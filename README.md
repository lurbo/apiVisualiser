# apiVisualiser

Ta aplikacija je bila ustvarjena v okviru predmeta IMA - Izdelava mobilnih aplikacij

Ustvarjena je bila v okolju Expo, njen namen pa je uporaba zunanjega API za prikazovanje vsebine v tej aplikaciji.

Uporablja se Open-Meteo API za pridobivanje trenutnih vremenskih podatkov za kraje katere vnašamo v TextInput ter se s pomočjo Geo-Coding API pretvorijo v koordinate za vremenski API.

Ima okno explore, ki o izbranem kraju pokažejo več detajlov ter zunanje povezave, ki se prilagajajo glede na parameter kraj, ki se prenese iz Index.

Pridobi trenutne podatke:
- Temperatura
- Hitrost vetra

V podoknu explore možnost vrnitve in izbire različnih zunanjih povezav.
Linki so prikazani v flatlistu, s sliko shranjeno v programu.
